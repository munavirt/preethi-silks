MOTION DESIGN

The website should have a noticeable sense of polish through motion.

Use animation strategically.

Recommended technologies:

GSAP

For:

ScrollTrigger

Section reveals

Image masks

Typography animation

Scroll-based movement

Anime.js

Use where it genuinely improves small UI interactions or micro-animations.

Framer Motion

Can be used for:

React component transitions

Navigation interactions

Hover states

Component-level animation

Do NOT use all animation libraries just because they are available.

Choose the right tool for each interaction.

If GSAP is sufficient, use GSAP.

If Framer Motion is cleaner for a React interaction, use Framer Motion.

Anime.js should only be used where it provides real value.
